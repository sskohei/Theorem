# ADR-0007 Phase 2 のライブラリ移行・再認識・チャット実行の相関

- **ステータス** Accepted
- **日付** 2026-11-26
- **関連フェーズ** Phase 2

## FormulaDesk ライブラリの移行

新ライブラリの保存先が未作成か空の場合、起動時に同じ親ディレクトリの旧 `dev.formuladesk.app` を探索する。旧 DB の読み取り専用接続から `VACUUM INTO` で WAL のコミット済みデータを含むスナップショットを作成する。添付・ソース・サムネイル・テンプレート・設定・バックアップを兄弟の一時ディレクトリへコピーし、設定の読み込みと DB マイグレーションの後にディレクトリをリネームして公開する。

中断した作業ディレクトリは公開先の判定から外れるため、次の起動で旧ライブラリを再読込できる。既存の新ライブラリがある場合は新ライブラリを開く。旧 ZIP を復元する場合は新ライブラリの `backups/` に置き、ストレージ設定から選択する。移行でコピーされた旧 ZIP も同じ画面に表示される。復元時は DB の旧ファイル名を現在のファイル名へ正規化し、ZIP の展開、設定の読み込み、スキーマ移行を一時領域で完了させてから反映する。ファイルを反映し、最後に DB を交換する。反映中の I/O エラーに備えて、上書きするファイルのコピーを一時保持する。

## 問題認識

既存問題は再認識時にも保存する。ページが重なるかページ情報が不明な場合、問題番号と小問番号の組、または問題文の一致を手がかりに既存候補を調べる。既存行や同じ応答内の候補と競合する項目は追加を見送る。入力ページが一つならそのページを出典とする。複数ページでは送信した範囲を出典の上限とし、ページ指定で出典不明の項目は追加を見送る。既存問題に対する変更は手動編集から行う。再認識は照合と追加を一つの書き込みトランザクションで実行する。

原本タブと認識タブは同じ PDF.js 入力生成を使う。ページ番号と PNG を組で渡し、切り出しには作成元のページを付ける。準備に失敗した場合は UI にエラーを出し、Rust でも資料の内容が空の要求をエージェント起動前に拒否する。

## チャット

チャット送信側が UUID を生成して IPC に渡し、Rust は同じ UUID を永続化とイベント配信に使う。ストリーム・計算ツールのイベント・権限要求・失敗・中断は UUID で実行に関連付ける。文書の読み込み、選択、メッセージ取得の世代を追跡し、別の会話へ切り替えた後に届く成功・失敗応答は現在の表示に反映しない。送信先には送信を開始した時点の文書と会話を使用する。
