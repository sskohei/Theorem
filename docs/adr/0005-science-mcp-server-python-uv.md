# ADR-0005: Science MCP Server（Python / uv / AST 安全パーサー）の採用

- **ステータス**: Accepted（エンドユーザー向け Python ランタイム配布方式は Phase 6 で確定）
- **日付**: 2026-11-25
- **関連フェーズ**: Phase 3 / Phase 6

## コンテキスト（背景・課題）

LLM 単体では複雑な微積分・行列演算・微分方程式・物理単位変換・次元解析で計算ミスやハルシネーションが起こり得る。また関数グラフや数値プロットを正確かつベクター形式で生成する必要がある。一方で、任意の Python コードを AI に実行させると、プロンプトインジェクション経由のローカル RCE（リモートコード実行）リスクが極めて高くなる。

## 決定内容

- 数学・物理計算およびグラフ生成を **Python（`uv` 依存管理）のローカル MCP サーバー（`science-mcp`）** として独立実装する。
- 計算ライブラリとして **SymPy / NumPy / SciPy / Pint / Matplotlib** および **MCP Python SDK** を採用する。
- **任意 Python 実行ツールを一切提供しない**。さらに `eval` / `exec` および生 `sympy.parse_expr` 呼び出しを禁止し、**Python `ast` モジュールによる厳格なホワイトリスト数式パーサー**、ワーカーサブプロセス隔離、ハードタイムアウト、固定 `artifacts/` ディレクトリ出力を必須とする。
- AI ハーネスへの登録はユーザーのグローバル MCP 設定を変更しないセッションスコープ方式とする。

## 検討した代替案

1. **Rust ネイティブのみで記号計算・プロットを実装**: SymPy・SciPy・Pint・Matplotlib に匹敵する成熟した大学数学・物理ライブラリ群が存在せず、開発コスト・計算精度で大きく劣る。
2. **AI ハーネス付属のシェル/Python 実行ツールをそのまま許可**: 任意コマンド実行・ローカルファイル漏洩のリスクが高く、FormulaDesk のセキュリティ要件に反する。

## 結果・トレードオフ・リスク

- **利点**: 大学数学・物理の広範な計算・検証・グラフ描画を安全に提供でき、MCP 標準により複数 AI ハーネスから再利用可能。
- **トレードオフ**: Windows 等のエンドユーザー環境における Python / `uv` ランタイムおよび依存パッケージの配布・起動時間最適化が Phase 6 の課題となる。
